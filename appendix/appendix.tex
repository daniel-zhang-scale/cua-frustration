\section{The Hard Split}
\label{app:hard}

The 51 tasks come from ansible (8), openlibrary (8), flipt (7), teleport (6), webclients (5), qutebrowser (4), vuls (4), element-web (4), navidrome (3), NodeBB (1) and tutanota (1). A task qualified if at least two of five model families fail on it across runs. That gave 54 candidates and 3 were removed after expert review. Every Hard task passes its reference solution, fails with an empty patch, and is solved by at least one of our runs. 39 of the 51 instructions were edited in the final review after selection.

\section{Harness Study}
\label{app:harness}

\paragraph{Setup.} GLM-5.3 (thinking on), Kimi K3 (reasoning effort max) and Inkling (xhigh) ran with a 1M-token context window and no cap on thinking tokens or turns; the only cap besides the 50-minute budget is mini-swe-agent's default 30\,s per-command timeout, which is part of that scaffold. Versions: Harbor 0.22, mini-swe-agent 2.4.6, Pi 0.85.0, OpenCode 1.18.29. Before the runs we patched the task images on which Pi or OpenCode would not install (older Alpine images lacking a recent \texttt{libstdc++}, and Debian~11 images whose end-of-life package sources broke OpenCode's installer); the patches add system packages only, and all nine combinations ran on the same patched images. We release the 5{,}778 trajectories with per-trajectory feature files.

\paragraph{Attempt rule.} Unlike the runs of \S\ref{sec:experiments}, these were graded once, in the container the agent had used. Every task has one counted attempt per model--scaffold combination; an attempt that hit the budget is graded on the patch present at the deadline. An attempt that hit the budget or was killed by infrastructure \emph{without} a passing grade was run once more at lower concurrency and the re-run is the counted attempt; a re-run never replaced a graded pass, and the rule was applied identically to all nine combinations. Pi and OpenCode place a different Node binary on the agent's path than the grader uses; in 13 trials an agent rebuilt a native module against it and the grader then crashed on that module (Kimi K3: 5 under Pi, 2 under OpenCode; GLM-5.3: 2 and 2; Inkling: 2 under OpenCode), and those trials count as failures.

\paragraph{Outcomes.} Table~\ref{tab:pairs} gives the paired comparisons behind \S\ref{sec:harness}. Splitting the variance of solved-or-failed over the 642 tasks every combination attempted, task identity accounts for 31.7\%, the model for 2.65\%, the scaffold for 0.29\% and the model--scaffold interaction for 0.36\%; the residual 65.0\% is task-by-run variation.

\paragraph{Validation.} Pass rates are one attempt per task, a standard error of 0.6--1.4 points per combination. The activity shares of Figure~\ref{fig:harness}b and the verification rates of \S\ref{sec:harness} come from a classifier that reads the first executable of each segment of a shell command; it matched a manual read on 147 of 150 sampled commands and on 97.2\% of sampled wall-clock, and the test-outcome detector behind the red-to-green rates matched on all 32 of 40 sampled test outputs it labelled, leaving 8 undecidable. Step time includes model latency, and test-file edits are under-counted under mini-swe-agent, where edits arrive as heredocs.

\section{Reproducibility}
\label{app:repro}

\paragraph{Harness.} Harbor 0.22.0 on Modal 1.5.5. The network is set per phase: public during setup, only the model endpoint during the agent phase, public again for the verifier, because 32 tasks download dependencies while testing. Claude Code 2.1.278 with web tools disabled; Codex 0.155.1 with hosted web search disabled; mini-swe-agent 2.4.6 with no step or cost limit, so the time budget binds.

\paragraph{Budget and grading.} The budget is 3000\,s per task. The agent is stopped at 2940\,s and the patch present then is graded. The patch is the staged \texttt{git diff} of the working tree; it is applied to a fresh container built from the task image, with a three-way fallback, and the unchanged verifier runs. When the sandbox grade and the clean grade disagree, two more clean grades are taken and the majority of the three counts. Mean API spend per task on V2 was \$2.9 for the Claude Code runs, \$2.3 for Astra and \$3 for Gemini.

\paragraph{Release.} Task directories, the Hard split, the probe, capture and re-grade scripts, the exact harness flags, per-task grades in both modes for every run, and the harness-study trajectories.
